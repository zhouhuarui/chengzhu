# 09 · 合规边界、风险提示与演示交付计划

> 赛题边界原文："本赛题强调金融辅助场景，不鼓励直接提供确定性投资建议、信贷审批结论、保险赔付结论或其他替代专业机构决策的内容。"
> 本文档的每一条都必须在代码或文案中落地，执行 Agent 不得省略。

---

## 1. 合规边界（系统行为红线）

### 1.1 禁止输出清单（审校 Agent 的拦截规则，需实现为规则 + LLM 双重检查）

| 类别 | 禁止示例 | 允许的替代表述 |
|------|---------|---------------|
| 投资建议 | "建议买入/卖出/持有"、"目标价 X 元"、"值得投资" | "以下为公开信息整理，投资决策请咨询持牌机构" |
| 确定性预测 | "股价将上涨"、"业绩必然改善" | "公司在公告中预计…（来源：[E3]）" |
| 估值判断 | "当前估值便宜/高估" | "当前市盈率为 X（数据截至…），行业中位数为 Y" |
| 荐股排序 | "最值得关注的三只股票" | 不生成此类内容 |
| 转述失范 | 把券商评级当系统结论输出 | "XX证券给出'买入'评级（此为该机构观点）" |

规则层实现：`backend/app/services/compliance_checker.py` 维护正则黑名单（建议买入|卖出|目标价|必涨|抄底|建仓 等，完整词表见 03 文档审校 Agent 节）；LLM 层实现：审校 Agent 的系统 Prompt 含合规检查职责，命中即改写并记录。

### 1.2 数据合规

- 仅使用**公开披露渠道**：巨潮资讯网（证监会指定信息披露平台）、交易所官网、东方财富/新浪/财联社公开页面、博查搜索（内容合规、数据不出海的国内服务商）。
- 不抓取需登录/付费的内容（研报只用公开列表页的标题+机构+评级，不破解 PDF 下载）。
- akshare 数据声明"仅供学术研究"——比赛材料中明确本项目为**参赛演示/研究用途**，商业化前需替换为持牌数据商（Wind/聚源/Tushare Pro 商业版）并在迭代计划中写明。
- 遵守目标网站 robots 与频控：全局限速器（04 文档第 2 节）为强制实现项。

### 1.3 隐私与数据授权

- 用户上传材料仅存储于本地 `backend/uploads/`，除调用 LLM API（阿里百炼，服务器在境内）外不发送给任何第三方；
- 不收集用户身份信息；用户反馈数据仅用于本地经验规则库，可在"我的偏好"页一键清除（需实现 `DELETE /api/memory/user` 接口）；
- 所有 API Key 只从 .env 读取，前端代码与仓库中不得出现任何 Key（.gitignore 必须含 .env）。

### 1.4 模型与内容安全

- LLM 使用阿里百炼（已通过大陆生成式 AI 备案的服务商），不接境外模型 API；
- 报告生成温度 <= 0.5，事实性章节要求"仅基于证据卡内容写作"，无证据不写（03 文档 Prompt 已含）；
- 每份交付物、每个前端页面页脚固定展示免责声明（见下）。

## 2. 固定免责声明文案（常量，放 `backend/app/constants.py`，前后端共用）

```
DISCLAIMER = (
  "本报告由 AI 系统基于公开信息自动整理生成，仅供信息参考与研究学习，"
  "不构成任何投资建议、证券推荐或收益承诺。文中涉及的券商评级、盈利预测均为"
  "相应机构观点。信息可能存在遗漏、延迟或错误，请以官方披露为准。"
  "投资有风险，决策需谨慎。"
)
DATA_NOTICE = "数据来源：巨潮资讯网、东方财富、新浪财经、财联社等公开渠道；数据截至：{timestamp}。"
```

### 1.5 仿真推演的合规边界（10 文档 §7 的执行摘要）

推演模块合规的核心逻辑：**赛题不鼓励的是"确定性投资建议与替代专业决策的结论"，而非情景分析本身**——情景推演（scenario analysis）是持牌机构研究业务的常规方法。本系统通过四道设计保证推演不越界：
1. 双情景成对推演（悲观/基准），报告呈现差异观察而非单一未来；
2. 推演内容强制"模拟/情景/沙盘"限定语，与真实事实（E 角标 vs S 角标）在视觉与数据层双重隔离；
3. 禁止外推黑名单（`股价将|必然导致|应及时买卖`等），Reviewer 拦截；
4. 每份推演报告头部固定模拟声明横幅 + 必选"局限性"章节（披露 agent 规模、轮数、模型简化假设）。
答辩口径：推演回答的是"该情景下**舆论与信息传导**可能如何演化"，不回答"股价会怎样、该不该买"。

## 3. 风险提示的产品化呈现

1. 报告"风险与关注点"章节只罗列**公司自行披露的风险因素**（年报"风险提示"节、问询函等）与**已发生的公开负面事件**，不做主观风险评级；
2. 任何数据缺失/降级（如某数据源当日失效）必须在报告尾部"数据完整性说明"中披露；
3. 追踪简报中的"下期关注点"只允许指向**已知日程**（如"4 月 28 日将披露一季报"来自交易所预约披露时间表），不做走势猜测。

## 5. 演示视频脚本（约 6 分钟）

1. **0:00-0:30 痛点**：快切研究员在巨潮/东财/财联社等 5 个网站间切换的画面 → "信息散、厚、对比难、追踪断、不会推演、工具不懂你"。
2. **0:30-1:00 需求输入**：输入"整理宁德时代 2026Q1 以来的公告要点、财务变化和研报观点，并与比亚迪做对比，开启每周追踪"，系统回显任务卡，修改时间窗后确认。
3. **1:00-2:15 多 Agent 编排实况**：任务运行页，镜头给到五个采集 Agent 并行的动作流水、证据计数器上涨、图谱节点增长动画、分析 Agent 的 ReACT 思考流、审校 Agent 拦截一条"值得买入"表述并改写（**特写，合规加分点**）。
4. **2:15-3:00 报告与追问（含多模态）**：引用角标点开即溯源；财务趋势 ECharts 图表（图下溯源角标特写）；对话追问"存货大幅上升在哪份公告里有解释？"，Agent 调用 read_announcement 定位原文，其中扫描版附件由 qwen-vl 视觉解析（**多模态加分点，给一个"视觉解析"标签特写**）。
5. **3:00-4:15 仿真推演（能力高潮）**：在"风险与关注点"点击「推演此情景」→ 确认"业绩预告低于预期"双情景配置 → 快进展示模拟广场中机构/分析师/媒体/散户的舆论演化（角色徽标着色）→ 推演报告的多空分歧图谱与双情景对比 → 采访一位"卖方分析师"角色追问其转向理由 → 模拟声明横幅特写（**合规点**）。
6. **4:15-5:15 历史学习（差异化高潮）**：对"券商观点汇总"章节点踩并评价"我只要表格"；再跑一次同类任务（换成比亚迪），任务卡自动预填偏好、该章节自动变为表格呈现；切到"我的偏好"页展示学到的规则条目、命中规则任务星级对比、数据源健康度。
7. **5:15-6:00 收尾**：追踪订阅推送的增量简报 + 合规声明特写 + 技术架构一页图（成竹 Foresketch：胸有成竹，先画后行）。

## 6. 边界外事项（答辩被问到时的口径）

- Q：能不能告诉我该不该买？A：系统定位是投研信息整理辅助，不替代持牌投顾决策，这是赛题边界也是我们的产品红线，审校 Agent 在架构层面保证这一点。
- Q：数据是否可靠？A：全部来自官方指定披露平台与主流公开渠道，每条论断可点击溯源；数据缺失会显式披露而不是让模型编造。
- Q：商业化数据授权？A：Demo 用公开接口，商业化路线图中第一步即替换持牌数据商，架构上 tools 层已按可插拔设计。
